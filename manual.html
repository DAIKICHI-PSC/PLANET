1. はじめに

PLANET は、自動旋盤で使う NC プログラムを「数値を入力するだけで自動生成」するツールです。 図面のような寸法（径・Z 位置・R・送り・回転数など）を入力すると、旋盤の NC コード （G0 / G1 / G2 / G3 / T / S / F / M など）を生成します。

主な機能は以下の 5 つです。

  • NC プログラムの自動作成 — 前挽き・裏挽き・クロス・溝・穴加工・突切りの 6 大カテゴリ、 計 109 通りの加工パターンに対応（第 5 章）
  • 自動盤シミュレータ — 生成したプログラムを 2 次元的にアニメーション再生し、 工具軌跡と干渉を目視で確認（第 6 章）
  • 干渉チェック — 材料・安全マージンから機械的に衝突を検出し、該当行をハイライト（第 7 章）
  • 計算式 — R テーパ・三角関数・周速・材料費などの 9 種の計算（5.3 節）
  • 編集補助ツール — オフセット加算・検索置換・加工時間レポート・NC 行の自動整列（第 8〜10 章）

メイン画面には左右 2 つのエディタがあります。左側が本番プログラム用、右側が 作業（オフセット加算・検索置換の対象）用です。どの作業をするかは画面の画像ボタン（タイル）をクリックするだけです。

4. エディタの操作（整列・待ち合わせ検索・強調）

4.1 NC 行の自動整列

エディタ内でカーソルを矢印キー / Enter で別の行に移動すると、離れた行が自動で整列されます。 整列とは、各行を「コマンド＋値」の間にスペースを 1 つだけ入れる標準形に書き直すことです。

G01X10Z-5F0.1      →     G01 X10 Z-5 F0.1
T0101 M03 S2000    →     T0101 M03 S2000

すでに整列済みの行は変更されません。ファイルを開いたときも全行が同様に整列されます。

4.2 待ち合わせ検索（左右エディタの同期）

「ツール」グループの 待ち合わせ検索 チェックをオンにすると、一方のエディタでカーソルを 行移動したとき、もう一方のエディタで同じ「M コード行」を探してジャンプ・ハイライトします。

  • 検索対象は M を含む行で、スペースを取り除いて長さが 4 文字の行 （例：M03 / M099 など）です。
  • 一致行が見つからない場合は動きません。
  • オンにするとフォーカスが離れた後も選択範囲（ハイライト）が残ります。 オフのときはフォーカス離開時に選択が解除されます。

4.3 コード強調（● 印の挿入）

「ツール」グループの 14 個のチェックボックスで、エディタ内の指定コードの前に ●（丸印）を付けて視覚的に強調できます。チェックを ON にすると両エディタの該当箇所すべてに ● が付与され、OFF にすると外されます。

注意
「G強調」は G0 / G1 を含むすべての G に ● を付けます。 ● 印は NC コードとして意味はありません（機種によってはエラーになる場合もあります）。 不要になったらチェックを OFF にするか、●を強制消去ボタンで両エディタの ● を すべて削除してください。

5. NC プログラムの自動作成

5.1 共通の手順

メイン画面右側のカテゴリタイル（前挽き / 溝 / 裏挽き / クロス / 穴加工 / 突切り / 計算式）を クリックすると、そのカテゴリの「プログラム一覧」画面が開きます。一覧から欲しい加工パターンの リンクをクリックすると、プログラム作成画面が開きます。

メイン画面 → [カテゴリタイル] → 一覧画面 → [プログラムリンク] → 作成画面 作成画面 → [X で閉じる] → 一覧画面に戻る → [X で閉じる] → メイン画面に戻る

作成画面の構成

  • 数値入力グループ（右上）— 加工条件（材料径・Z 位置・R・送り・回転数など）。 項目はプログラムごとに異なります。
  • プログラム表示欄（右下）— 生成された NC プログラムが表示されます。
  • 図面イメージ（左）— 加工形状のイメージ図。

3 つのボタン

ボタン動作
プログラム作成
（計算式のみ「計算」）		 入力値から NC プログラムを生成し、右の欄に表示します。 必要な入力が無い場合は「○○が入力されていません。」と表示されて生成されません。
動作確認 生成したプログラムをそのまま自動盤シミュレータで実行します （6.1 節の 3 つの入力ダイアログが出ます）。
追加 生成したプログラムをメイン画面の左側エディタ末尾に追加します （既存の内容は消えません）。
おすすめの流れ
「プログラム作成」→「動作確認」でシミュレータ上で軌跡を確認 → 問題なければ「追加」で 左側エディタへ取り込み → 複数工程を続けて追加 → 最終的に上書き保存、が標準的な使い方です。

6. 自動盤シミュレータ

6.1 起動方法

メイン画面の シミュレータタイル（左下 1 列目）をクリックするか、 プログラム作成画面の 「動作確認」ボタンを使うと、以下の 3 つの入力ダイアログが 順番に表示されます。

ダイアログ説明初期値
材料の素材径を入力して下さい。 ワーク（材料）の直径（mm）。画面の材料断面がこれに合わせて描画されます。 なし（必須）
ガイドブッシュの超硬長を入力して下さい。 ガイドブッシュの超硬部分的な長さ（mm）。ブッシュの描画に使われます。 15
刃先基準位置からガイドブッシュまでの距離を入力して下さい。 工具の基準位置（T 交換位置）とブッシュ端の距離（mm）。 2

どのダイアログでもキャンセル（OK 以外）を選ぶとシミュレータは起動しません。 実行中のプログラムは「左側エディタの内容」です（「動作確認」から起動した場合は 生成したプログラム）。

ウィンドウタイトルは PLANET-自動盤シミュレータ で、最大化状態で開きます。

6.2 画面の構成

┌──────────────┬────────────────────────────────────────────────┐ │ 程序リスト │ │ │ (lb1) │ │ │ │ 加工面（Canvas） │ │ G0 X40 Z0 │ 材料断面・ガイドブッシュ・工具軌跡 │ │ G1 X10 Z-5 │ をアニメーション表示 │ │ ... │ │ ├──────────────┤ │ │ 工具リスト │ │ │ (lb2) │ │ │ 選択なし │ │ │ M01を選択 │ │ │ M02を選択 │ │ └──────────────┴────────────────────────────────────────────────┘ 左カラム幅 232px（工具リスト高さ 132px 固定）／残りは Canvas
  • 程序リスト（左上） — プログラムが実行されるごとに 1 行ずつ追加されます。 実行中は現在行がハイライトされ、画面下までスクロールします。
  • 工具リスト（左下） — 1 行目が「選択なし」、以降が M○ を選択 の形で T コードごとに追加されます（M コード値 100 以上を工具交換と認識）。 実行结束后に工具を選択すると、程序リストがその工具の 1 行目にジャンプします。
  • 加工面（右） — 材料断面（円柱の断面）、ガイドブッシュ（上下 2 本）、 各工具の軌跡、工具そのものを描画します。初期表示は 1 倍（1mm≈数 px）、 原点が画面中央に来るように自動調整されます。

6.3 プログラムの実行

  1. メニューの 「実行(&S)」（メニューバー右端）をクリックします。
  2. 程序リストに 1 行ずつ追加され、工具が NC コードに従ってアニメーション移動します。 実行中は「実行」メニューがグレーアウトし、工具リストも選択不可になります。
  3. プログラムが終わり（または Esc で中断）すると、 「実行」が再有効になり、工具リストも選択可能になります。

実行中のキー操作

キー動作
Enter / Return 「加工動作検証ツール」メニューの 「プログラムを一行で停止(&F)」を ON にすると、 各行の実行後ポーズします。Enter で次行へ実行を進めます（ステップ実行）。
Esc 実行を即停止します（中断）。
実行速度
「加工動作検証ツール → 実行スピード(&P)」で X1（デフォルト）/ X2 / X4 / X8 / X16 を 切り替えます。送り F とともに移動の細かさ（1 ステップ量）が変わります。

7. 干渉チェック（3 種類）

メイン画面の右上 3 つのタイル（シミュレータタイルの横）で、左側エディタのプログラムを 機械的に解析し、材料・安全マージンに対して工具が衝突する行を検出します。 結果は PLANET 干渉チェック ウィンドウ（549×571）に、 プログラム行のリストとして表示され、問題のある行だけが選択（ハイライト）されます （複数選択モード）。

共通の動作
チェック中に「X 軸が材料の中心を越えました（X−○）。（同様に Y 軸の場合）」の確認ダイアログが出ることがあります。 これは工具がすでに加工した面の中心側まで入ったことを検知したもので、 「はい」を選ぶと「加工済み面」の位置をその Z 位置に更新してチェックを続行します（材料が切られた可能性の確認）。

7.1 チェック 1：干渉チェック（基本）

入力説明初期値
材料の素材径ワーク直径（mm）なし（必須）
径方向（XY）の安全マージン「材料径＋入力値」以上の範囲を安全圏とします1.0
軸方向（Z）の安全マージン「Z0＋入力値」以下の範囲を安全圏とします−0.5

工具の動き（G0/G1/G2/G3、X/U/Z/W/Y/V、T、G92 シフト、ミル径 D）を追跡し、 安全圏外に工具が侵入する行を検出します。工具番号 100 以上（T コード）の 括弧内注釈 (X… Y… D…) を読んで加工面（X 面 / Y 面）とシフト量・ミル径を特定します。

7.2 チェック 2：干渉チェック（高速送り検出）

チェック 1 の 3 項目に加えて、

入力説明初期値
安全な送りの最大値「入力値以下の送り」を安全とします0.05

G1 加工中（G01）で F が安全値を超えていて、かつ安全圏外に入る行を検出します。 つまり「高速で突っ込む」動きを見つけます。

7.3 チェック 3：干渉チェック（Z 位置検出）

入力説明初期値
工具位置決めのＺ値工具設定（T 交換）時の Z 位置（mm）5.0
クリアランス「位置決めの Z 値＋入力値」で接触とみなします0.5
Ｚ軸の安全マージン「入力値以上の範囲」を安全圏とします−0.5
安全な送りの最大値「入力値以下の送り」を安全とします0.05

Z 絶対値移動が「安全圏（位置決め Z + クリアランス + 安全マージン）」を超える行、 高速送り（F>安全値）で安全圏内へ Z 進入する行、X/Y 軸を動かす行（工具が材料上面を横切る可能性）、 T コード / M コードで安全 Z 位置より上にある行を検出します。

8. オフセット加算（X / Y / Z / F）

メイン画面の中央 4 つのタイル（S_X / S_Y / S_Z / S_F）で、 右側エディタのプログラムから全 X / 全 Z / 全 Y / 全 F の値に一定値を加算します。 （右側エディタにプログラムが無い場合は「右側編集画面にプログラムがありません。」と表示されます。）

タイルダイアログ効果
X 加算右側編集画面の全Ｘ軸に入力値を加算します。X に加算する値を入力して下さい。 各行の X（および U 相当の絶対 X に影響する値）に値を加算
Y 加算…全Ｙ軸に…各行の Y に値を加算
Z 加算…全Ｚ軸に…各行の Z に値を加算
F 加算…全Ｆ値に…各行の F に値を加算
用途
「全工程を Z で 0.5 mm 深くする」「全送りを 0.01 速くする」ような一括修正に使います。 結果は行を 1 行ずつ コマンド 値 コマンド 値 の整列形に書き直して右側エディタへ戻ります。 加算は絶対値（X/Z）に対して行われるため、相対値（U/W）行はそのままになります。

9. 検索・置換

「Replace」タイル（置換）で、右側エディタ内の文字列を検索して置換します。

  1. 「右側編集画面で検索する文字列を入力して下さい。」に検索文字列を入力（例：M03）
  2. 「検索した文字列と置き換える文字列を入力して下さい。」に置換文字列を入力（例：M04）

置換は全件・区別なしで行われ、置換後の文字列の前に● が自動的に付与されます （例：M03 → ●M04）。これにより変更箇所を目視で確認できます。 ● が不要になったら「●を強制消去」ボタンで削除できます。 （右側エディタが空の場合はエラー表示されます。）

10. 加工時間レポート

「Time」タイル（時計）で、左側エディタのプログラムから加工時間を推定します。 左側エディタが空の場合はエラー表示されます。

入力

入力説明初期値
Ｇ０に相当するＦ値G0（空送り）の移動速度として使う F 値（mm/回転）2.0
安全に加工する事が出来る送りの最大値この値以下の F を「安全送り（実加工）」とみなす上限0.05

レポートの内容

総加工時間は ○秒(○分○秒) です。

１時間で ○個 加工出来ます。
１日で ○個 加工出来ます。

Ｇ４での一時停止時間は ○秒 です。
Ｇ０の移動時間は ○秒 です。
Ｇ１の加工時間は ○秒 です。
Ｇ９２の加工時間は ○秒 です。

総平面移動距離は ○mm です。
Ｇ０の平面移動距離は ○mm です。
Ｇ１の平面加工距離は ○mm です。
Ｇ９２の平面加工距離は ○mm です。

加工する際の送りの平均は F○ です。
回転数の平均は S○ です。
計算方式
・移動距離は X（÷2）・Y（÷2）・Z の最大値を 1 行の平面移動距離とします。
・G0 は入力された F 値で、G1 は各 F 値と S（回転数）から時間を算出 （距離 ÷ F × 60 ÷ S の方式）。
・G4（ dwell ）の時間はそのまま加算。
・G92 は X 移動（÷2）・Z 往復（W×2）分を G0 相当と G1 相当の両方で計上。
・工具交換（T○○○、100 以上）で位置は X60/Y60 にリセットされ、G0 扱いになります。
・F ≤ 安全送り最大値の行について送りの平均、実行行について回転数の平均を出します。

11. 終了

メイン画面の ×（閉じる）ボタンをクリックすると、 「現在の内容は破棄されます。終了しますか？」と確認されます。

  • はい — シミュレータが開いていれば即座に終了処理（実行中でも停止）が行われた後、 アプリ全体が終了します。
  • いいえ — 何も起こらず画面に戻ります。
注意
未保存の内容は破棄されます。終了前に上書き保存してください。

12.4 既知の仕様（オリジナル版との互換性）

  • メイン画面のツールメニュー（ツール(&T)）はオリジナル版と同様に表示されません （元プログラムにイベントが無いため）。
  • リスト画面（一覧）はオリジナル版と同様に 縦スクロールで対応します （突切りのみ 1 項目なのでスクロールバーは出ません）。
